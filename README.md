# Spotify Overview Dashboard

## Overview
A modern Spotify-inspired Power BI dashboard combining music analytics with a creative user interface to present artist statistics, song distribution, and popularity trends.

## Key Features
- Total Songs and Artists KPIs
- Average Popularity Score
- Song Distribution by Artist
- Album Type Analysis
- Monthly Popularity Trends
- Custom Spotify-Inspired Dashboard Layout
- Glassmorphism-Style UI Design

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Dashboard UI/UX Design
- Data Analysis
